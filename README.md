# 📊 Tableau Projects

A collection of datasets used to build data-visualization dashboards in [Tableau Public](https://public.tableau.com/app/profile/kamil.molasy). Each dataset in this repo backs a published Tableau dashboard — open the spreadsheet to inspect the raw data, or follow the link to see the finished visualization.

## 📌 What's Inside

- `Coffee Caffeine Content.xlsx` — caffeine content (mg) by chain, product and drink size (`Chain`, `Product`, `Caffeine (mg)`, `Drink size (ml)`)
  - Dashboard: [Coffee Caffeine Content](https://public.tableau.com/app/profile/kamil.molasy/viz/makeovermonday2023w9/Dashboard1?publish=yes)
- `Global Electric Vehicle Market Share_1.xlsx` — quarterly EV market share by brand, Q2 2021 – Q3 2022
  - Dashboard: [Global Electric Vehicle Market Share](https://public.tableau.com/app/profile/kamil.molasy/viz/ElectricVehicle_16772310439260/Dashboard1?publish=yes)
- `wbb_rosters_2022_23.xlsx` — NCAA women's basketball rosters for the 2022–23 season (team, player name, class year, hometown, high school, etc.)
- `wbb_teams.xlsx` — NCAA women's basketball team reference data (team, conference, state, social/stats links)

## 🚀 Getting Started

```bash
git clone https://github.com/kagap/tableau_project.git
cd tableau_project
```

- Open any `.xlsx` file directly in Excel/Google Sheets to explore the raw data.
- Or open it as a data source in [Tableau Desktop / Tableau Public](https://www.tableau.com/products/public) to rebuild or extend the dashboards.
- Finished dashboards for the Coffee and EV datasets are linked above on Tableau Public.

## 🛠️ Requirements

- Tableau Desktop or Tableau Public to open/build `.twb`/`.twbx` workbooks from these sources.
- Any spreadsheet app to view the `.xlsx` files directly.
